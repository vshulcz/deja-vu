快速开始

装十秒，建索引十秒，然后智能体就能查自己的历史了

安装

curl -fsSL https://raw.githubusercontent.com/vshulcz/deja-vu/main/install.sh | sh
deja install --auto

第二条命令做三件事：把 MCP 召回接到它在这台机器上找到的每一个智能体，在支持的地方打开会话启动时的自动召回，并建好第一份索引。也可以用 Homebrew（brew install deja-vu）或从 releases 直接下二进制。

建索引读的是你磁盘上已经有的会话记录，所以第一次跑完，你几个月前的工作就已经能搜到了——不需要提前记录任何东西。

先确认它看到了什么

deja sources
deja stats

sources 列出它在每个工具下找到的路径和会话数；stats 给出索引里有多少会话、来自哪些项目、活跃度如何。如果某个工具没被认出来，支持矩阵里有它期望的路径和对应的环境变量。

自己搜一下

$ deja "connection pool exhausted"
[claude] api   · Jul 8 · 8f31c0a9 — 2 matches
  login started failing after refresh token rotation; jwt kid mismatch in tests
  fixed by reloading jwks cache after rotateKey and adding a clock-skew test
[codex]  web   · Jul 1 · b77d91e2 — 1 match
  refresh token cookie needed SameSite=Lax in local callback flow

几条常用的：

  • deja "报错原文" —— 跨所有工具搜历史。
  • deja fix "报错原文" —— 上次这个报错之后，真正跑通的是哪条命令。
  • deja how "docker build" —— 你在这台机器上实际用过的调用方式。
  • deja show <id> —— 打开某一个会话；deja last 列出最近的。
  • deja blame <文件> —— 哪些会话动过这个文件、当时在做什么。

让智能体自己去查

deja install --auto 已经把这条路接好了。之后是智能体自己发起召回，不用你开口：会话开始时、提问命中过去的工作时、改文件或执行命令之前、命令失败之后。哪个工具支持哪一个时机，见agents 指南。

只想手动用也完全可以：不接自动召回，deja 就只是一个命令行搜索工具。

关于隐私

索引和检索都在本地，默认不需要网络、账号或 API key。建索引时凭据会被脱敏。除非你显式配置了远程 embedding 端点，否则没有任何内容离开这台机器——细节见隐私说明。

不想要了

deja uninstall --all
rm -rf ~/.cache/deja

会话记录本来就是各个工具自己写的，deja 不动它们。
