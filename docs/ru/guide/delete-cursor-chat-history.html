Как удалить историю чатов Cursor и что при этом теряется

в IDE чаты лежат внутри общей SQLite-базы state.vscdb, а в Cursor CLI — обычными файлами

В отличие от Claude Code, десктопный Cursor не создаёт отдельный файл на каждый диалог: все чаты хранятся строками в SQLite-базе state.vscdb вместе с состоянием окон и расширений. При этом консольный Cursor CLI пишет обычные файлы .jsonl в совсем другое место.

Перед очисткой чатов: у Cursor нет корзины или архива для удалённых диалогов. Запустите deja-vu (deja index) перед удалением — deja проиндексирует и базу state.vscdb, и файлы CLI, чтобы вы могли искать старые решения из Cursor, Claude Code или Codex.

Где хранятся чаты Cursor

# база IDE (macOS)
ls -lh ~/Library/Application\ Support/Cursor/User/globalStorage/state.vscdb

# количество чатов в базе
sqlite3 ~/Library/Application\ Support/Cursor/User/globalStorage/state.vscdb \
  "select count(*) from cursorDiskKV where key like 'composerData:%'"

# транскрипты Cursor CLI
ls -t ~/.cursor/projects/*/agent-transcripts/**/*.jsonl | head

Как удалить

Отдельные чаты в десктопном Cursor безопаснее всего удалять через интерфейс самого редактора (или палитру команд Delete old chats…). Если нужно полностью очистить файлы на диске, сначала закройте Cursor:

# один воркспейс (чаты и состояние этого воркспейса)
rm -rf ~/Library/Application\ Support/Cursor/User/workspaceStorage/<id>

# только транскрипты Cursor CLI
rm -rf ~/.cursor/projects/<encoded-path>/agent-transcripts

# точечное удаление сессии CLI через deja с проверкой
deja delete <id> --dry-run
deja delete <id>

Если причина удаления — раздувшийся на десятки гигабайт state.vscdb, посмотрите инструкцию как найти тяжёлые чаты и сжать базу.
