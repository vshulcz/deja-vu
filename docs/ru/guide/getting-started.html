Быстрый старт

десять секунд на установку, десять на индекс — и агенты помнят всё, что вы уже чинили

deja-vu (github.com/vshulcz/deja-vu, CLI deja) — локальный инструмент памяти и поиска по истории сессий для кодинг-агентов. Он индексирует транскрипты, которые Claude Code, Codex, Cursor, Qwen Code, Gemini CLI, opencode, Crush и ещё 36 агентов уже пишут на диск, и возвращает нужный контекст через MCP и хуки. Один Go-бинарник, без LLM и без облака.

Установка

curl -fsSL https://raw.githubusercontent.com/vshulcz/deja-vu/main/install.sh | sh
deja install --auto

Вторая команда подключает MCP-сервер deja ко всем найденным на машине агентам, включает автоматическую подгрузку контекста через хуки (на старте сессии, перед правкой файла, после ошибки команды и после компакции) и строит первый индекс. Также можно поставить через Homebrew (brew install vshulcz/tap/deja-vu), npm (npm i -g @vshulcz/deja-vu), Windows WinGet (winget install vshulcz.deja-vu) или Scoop (scoop install deja-vu).

Индекс строится по сессиям, которые уже лежат на диске, поэтому сразу после установки вся ваша работа за прошлые месяцы доступна для поиска. Хотите сначала посмотреть без установки? Откройте живое демо в браузере или выполните read-only проверку: npx @vshulcz/deja-vu sources покажет, сколько сессий уже сохранено у вас на диске.

Проверка найденных агентов

deja sources
deja stats

deja sources показывает пути и число сессий каждого найденного агента; deja stats выводит общую сводку по проектам и активности. Полный список путей для всех 43 агентов — в таблице поддержки.

Поиск в терминале

Запустите deja без аргументов — откроется интерактивный полноэкранный поиск по истории всех агентов. Вверху списка — сессии, связанные с текущими незакоммиченными изменениями, ниже — недавние сессии этого проекта.

Результаты обновляются по мере ввода: ↵ открывает сессию на найденном месте, r продолжает её в родном агенте, o переносит контекст в другой агент, вкладка Deleted показывает удалённые агентом сессии, которые сохранились в индексе deja. Из командной строки поиск работает так же:

$ deja "refresh token"
[claude] api   · Jul 8 · 8f31c0a9 — 2 matches
  login started failing after refresh token rotation; jwt kid mismatch in tests
  fixed by reloading jwks cache after rotateKey and adding a clock-skew test
[codex]  web   · Jul 1 · b77d91e2 — 1 match
  refresh token cookie needed SameSite=Lax in local callback flow
  • deja "текст ошибки" — поиск по истории всех агентов одновременно.
  • deja fix "текст ошибки" — какая команда в прошлый раз починила эту ошибку.
  • deja how "docker build" — как именно вы запускали команду в этом проекте.
  • deja blame <файл> — какие сессии меняли или обсуждали файл и почему.

Приватность

Индексация и поиск выполняются локально и не делают сетевых запросов. Ключи API, токены, приватные ключи и пароли автоматически вырезаются при индексации.

Удаление

deja uninstall --all
rm -rf ~/.cache/deja

Исходные файлы сессий ваших агентов deja никогда не изменяет.
