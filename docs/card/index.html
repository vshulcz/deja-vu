Your stats card, as a PNG

The card deja draws is an SVG, which a README renders and every social site refuses. This turns it into a PNG. The conversion runs in this page — the file never leaves your machine.

deja stats --card deja-stats.svg
drop deja-stats.svg here, or click to choose

Rendered at 2× so it stays sharp on a phone. Nothing is uploaded: the SVG is read with FileReader and drawn to a canvas locally. If you would rather not trust that, the script on this page is short enough to read.

No card yet? Install deja, then run the command above — it reads the sessions your agents already wrote to disk.
