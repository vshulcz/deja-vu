# deja-vu Raycast 扩展

在 Raycast 中搜索并恢复 Claude Code、Codex、Cursor、OpenCode、Gemini CLI 等 43 个编程智能体的本地会话。

## 前置条件

先安装 [`deja-vu`](https://github.com/vshulcz/deja-vu)：

```sh
brew install deja-vu && deja install --auto
```

## 命令与操作

- **Search Sessions**：全文搜索本机所有智能体会话（区分严格匹配与相关性近似结果）。
- **Recent Sessions**：浏览最近 100 条跨智能体会话及元数据预览。
- 支持查看完整对话、在 `Terminal.app` 中直接恢复会话、复制恢复命令及打开项目目录。
